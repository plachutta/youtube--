- **Root Cause**: The script calls `run_kdenlive_cli(['--no-welcome', '--render', PROJECT_FILE], wait_time=120)` but **Kdenlive's `--render` flag requires an output file argument**. The correct syntax is `kdenlive --render project.kdenlive output.mp4`. Without the output file, Kdenlive prompts interactively or returns error code 1 ("You need to give a non existing output file to render from the command line."). The script does not check the return code and proceeds regardless.
